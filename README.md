# SmartID Guardian v3.0

### C++20 Student ID & Campus Security Management System

SmartID Guardian is a console-based student identification and campus security management system developed using C++20. It helps manage student records, verify ID cards, report lost cards, revoke cards, and track campus entry and exit activities.

## 🚀 Features

- **Student Registration** – Register students with name, roll number, department, and ID expiry date.
- **Student ID Verification** – Verify student records and card status.
- **Lost Card Reporting** – Mark lost cards and block their verification.
- **Card Revocation** – Permanently revoke student cards.
- **Campus Entry Tracking** – Record student campus entry.
- **Campus Exit Tracking** – Record student campus exit.
- **Student Search** – Find student records using roll number.
- **Student Records Display** – View all registered students.
- **Dashboard** – View student statistics and campus status.
- **CSV Export** – Export student records to a CSV file.
- **Audit History** – View recorded system activities.
- **Data Persistence** – Save and load student records using local files.

## 🛠️ Technologies Used

- C++20
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)
- File Handling
- CSV File Export
- Data Validation

## ▶️ How to Run

**Requirements:** A C++ compiler that supports C++20.

Compile using:

```bash
g++ -std=c++20 main.cpp -o SmartIDGuardian
```

Run on Windows:

```bash
SmartIDGuardian.exe
```

Run on Linux:

```bash
./SmartIDGuardian
```

## 🎯 Project Purpose

This project demonstrates practical C++ programming concepts through a student ID and campus management prototype. It combines student record management, validation, file handling, reporting, and campus activity tracking in one application.

## ⚠️ Important Note

SmartID Guardian is an educational and portfolio project prototype. It is a console-based application and is not a replacement for a production-grade campus security system or physical access-control infrastructure.
