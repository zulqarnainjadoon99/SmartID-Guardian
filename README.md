# SmartID Guardian

**C++20 Student ID & Campus Security Management Prototype**

SmartID Guardian is a console-based C++ application for managing student identity records and demonstrating basic campus entry and exit tracking. It brings registration, ID verification, lost-card handling, record search, reporting, and audit history into one educational prototype.

## Features

- Register students with name, roll number, department, and ID expiry date
- Verify student records and card status
- Report lost cards and block their verification
- Revoke student ID cards
- Record campus entry and exit activity
- Search for students by roll number
- Display registered student records
- View a dashboard of student and campus status information
- Export student records to CSV
- Review system activity through an audit history
- Persist records using local files

## Technology & Concepts

- C++20
- Object-oriented programming and standard library containers
- File handling and local data persistence
- Input validation and record management
- CSV export and activity logging

## Project Files

| File | Purpose |
|---|---|
| `main.cpp` | Application source code |
| `students.db` | Local student record storage |
| `audit.log` | Activity history |
| `students_export.csv` | CSV export generated by the application |

The data files are created or used locally when the application runs.

## Build & Run

**Requirement:** A C++ compiler with C++20 support.

Compile:

```bash
g++ -std=c++20 main.cpp -o SmartIDGuardian
```

Run on Windows:

```bash
SmartIDGuardian.exe
```

Run on Linux:

```bash
./SmartIDGuardian
```

## Project Scope

This project demonstrates programming concepts for student record administration and simulated campus activity tracking. It is a console-based educational prototype, not a production identity-verification or physical access-control system. It does not replace secure institutional infrastructure.
